# Backend API для системы управления логистикой

## ⚠️ ВАЖНО: Порядок запуска

**Бэкенд ДОЛЖЕН быть запущен ПЕРЕД фронтендом!**

Если бэкенд не запущен, данные не будут сохраняться в БД и будут теряться при перезапуске.

## Установка

1. Установите зависимости:
```bash
npm install
```

## Запуск

```bash
node server.js
# или
npm start
```

Сервер запустится на порту 3001.

**После запуска бэкенда** откройте новый терминал в основной папке проекта и запустите фронтенд:
```bash
npm run dev
```

Для остановки сервера используйте `Ctrl + C`.

## Сохранение данных

- ✅ **Автоматически сохраняются в БД:**
  - Пользователи (при регистрации)
  - Заказы (при создании)

- ❌ **НЕ сохраняются в БД:**
  - Изменения статусов заказов (только в памяти)
  - Комментарии (только в памяти)
  - Данные автопарка (только в памяти)

## Проверка данных в БД

```bash
sqlite3 database.sqlite

# Просмотр всех заказов
SELECT * FROM orders;

# Просмотр всех пользователей  
SELECT * FROM users;

.quit
```

## База данных

Используется SQLite3. База данных автоматически создается при первом запуске в файле `database.sqlite`.

При первом запуске автоматически создаются тестовые пользователи:
- ИНН: `demo`, Пароль: `demo` (Грузоотправитель)
- ИНН: `7701234567`, Пароль: `shipper123` (Грузоотправитель)
- ИНН: `7709876543`, Пароль: `logist123` (Логист)

## API Endpoints

### POST /api/auth/login
Авторизация пользователя

**Request body:**
```json
{
  "inn": "demo",
  "password": "demo"
}
```

### POST /api/auth/register
Регистрация нового пользователя

**Request body:**
```json
{
  "inn": "1234567890",
  "password": "password123",
  "company": "ООО Компания",
  "userType": "shipper"
}
```

### POST /api/orders/create
Создание нового заказа

**Request body:**
```json
{
  "shipperName": "ООО Компания",
  "managerName": "Иван Иванов",
  "origin": "Москва, ул. Ленина, 1",
  "destination": "Санкт-Петербург, Невский пр., 1",
  "pickupDate": "2024-12-01",
  "deliveryDate": "2024-12-02",
  "transportationCost": 50000,
  "vehicleCount": 1
}
```
