# Объяснение проблемы с сохранением данных в БД

## Проблема

При перезапуске фронтенда (`npm run dev`) данные теряются, хотя они сохраняются в базе данных.

## Причина

**Фронтенд использует локальное состояние (useState)**, которое:
1. Инициализируется пустыми значениями при каждом перезапуске React приложения
2. Не загружает данные из базы данных при старте
3. Работает независимо от бэкенда - данные сохраняются в БД на бэкенде, но фронтенд об этом не знает

**Бэкенд работает правильно:**
- Данные успешно сохраняются в SQLite при регистрации пользователей и создании заказов
- База данных `database.sqlite` существует и содержит данные
- При перезапуске бэкенда данные остаются в БД

## Решение

Добавлены новые endpoints:
- `GET /api/orders` - получить все заказы из БД
- `GET /api/users` - получить всех пользователей (для отладки)

**Для полной интеграции нужно:**

1. **Загружать данные из БД при старте приложения:**
   - В `App.tsx` добавить `useEffect` для загрузки заказов из БД при монтировании компонента
   - Загружать данные после успешной авторизации пользователя

2. **Синхронизировать локальное состояние с БД:**
   - После каждого создания/обновления заказа - обновлять локальное состояние
   - Или периодически обновлять данные из БД

3. **Альтернатива:**
   - Использовать БД как единственный источник истины
   - Все операции делать через API, а локальное состояние использовать только для UI

## Текущее состояние

- ✅ Бэкенд сохраняет данные в БД
- ✅ БД существует и содержит данные после перезапуска бэкенда
- ❌ Фронтенд не загружает данные из БД при старте
- ❌ Фронтенд работает с локальным состоянием, которое теряется при перезапуске

## Рекомендации

1. **Краткосрочное решение:** Добавить загрузку заказов из БД в `App.tsx` при авторизации пользователя
2. **Долгосрочное решение:** Полностью перейти на работу с БД через API, убрать локальное состояние или синхронизировать его с БД

## Проверка

Чтобы убедиться, что данные сохраняются в БД:
1. Создайте заказ через фронтенд
2. Остановите фронтенд (`Ctrl+C`)
3. Проверьте БД: `sqlite3 backend-test/database.sqlite "SELECT * FROM orders;"`
4. Данные должны быть в БД, даже если фронтенд перезапущен
