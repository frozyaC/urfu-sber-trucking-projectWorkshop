# Интеграция с внешним API для загрузки водителей

## Описание

При нажатии на кнопку **"Добавить заказ"** в панели логиста система автоматически загружает водителей из внешнего MockAPI.

## API Endpoint

```
GET https://68fa3ce0ef8b2e621e7f53cf.mockapi.io/api/v1/drivers/name
```

## Формат ответа API

API возвращает массив объектов водителей в формате JSON:

```json
[
  {
    "name": "Penny Abshire",
    "phone": "1-760-957-6952 x9562",
    "licenseNumber": "137429172",
    "comment": "speedily",
    "id": "1"
  },
  {
    "name": "Ivan Petrov",
    "phone": "+7-495-123-45-67",
    "licenseNumber": "987654321",
    "comment": "Опытный водитель",
    "id": "2"
  }
]
```

## Обрабатываемые поля

Система извлекает и использует следующие поля из ответа API:

| Поле | Тип | Описание | Обязательное |
|------|-----|----------|--------------|
| `name` | string | ФИО водителя | Да |
| `phone` | string | Телефон для связи | Да |
| `licenseNumber` | string | Номер водительского удостоверения | Да |
| `comment` | string | Комментарий о водителе | Нет |

**Примечание:** Все остальные поля в ответе API (например, `id`) игнорируются системой.

## Логика работы

1. **Загрузка данных**: При нажатии кнопки "Добавить заказ" выполняется GET-запрос к API
2. **Парсинг данных**: Система извлекает необходимые поля из JSON-ответа
3. **Проверка дубликатов**: Перед добавлением проверяется, нет ли водителя с таким же номером ВУ
4. **Добавление в систему**: Новые водители добавляются со статусом "Не работает"
5. **Отображение результата**: 
   - Показывается уведомление о количестве загруженных водителей
   - Автоматически открывается раздел "Управление автопарком" на вкладке "Водители"
   - Все загруженные водители отображаются в таблице

## Статусы уведомлений

- ✅ **Успех**: "Загружено водителей: N"
- ⚠️ **Предупреждение**: "Все водители уже существуют в системе"
- ⚠️ **Предупреждение**: "Не найдено водителей для загрузки"
- ❌ **Ошибка**: "Не удалось загрузить водителей из API"

## Правила добавления

- Водитель добавляется только если все обязательные поля (`name`, `phone`, `licenseNumber`) присутствуют
- Если водитель с таким `licenseNumber` уже существует, он пропускается
- Новым водителям автоматически присваивается статус доступности "Не работает"
- Поле `comment` добавляется как есть, если пустое - используется пустая строка

## Просмотр загруженных водителей

После загрузки водители доступны в разделе:
**Панель логиста → Управление автопарком → Вкладка "Водители"**

Там отображается полная информация:
- ФИО водителя
- Телефон
- Номер ВУ
- Статус доступности
- Комментарий
