# 🚀 Быстрый старт - Загрузка водителей из API

## Как загрузить водителей из внешнего API

### Шаг 1: Войдите как Логист
1. Откройте приложение
2. Выберите тип пользователя **"Логист"**
3. Заполните форму входа и нажмите "Войти"

### Шаг 2: Загрузите водителей
1. На панели логиста найдите кнопку **"Добавить заказ"**
2. Нажмите на неё
3. Система автоматически:
   - Выполнит запрос к API
   - Загрузит всех водителей
   - Добавит их в базу данных
   - Покажет уведомление о результате
   - Откроет окно "Управление автопарком" на вкладке "Водители"

### Шаг 3: Просмотрите загруженных водителей
В открывшемся окне вы увидите:
- **ФИО** - полное имя водителя
- **Телефон** - контактный номер
- **ВУ** - номер водительского удостоверения
- **Статус** - доступность водителя (по умолчанию "Не работает")
- **Комментарий** - дополнительная информация

## Примеры уведомлений

### ✅ Успешная загрузка
```
Загружено водителей: 15
```

### ⚠️ Есть дубликаты
```
Загружено водителей: 12 (пропущено дубликатов: 3)
```

### ⚠️ Все уже загружены
```
Все водители (15) уже существуют в системе
```

### ❌ Ошибка загрузки
```
Не удалось загрузить водителей из API. Проверьте подключение к интернету.
```

## Дополнительные действия с водителями

После загрузки вы можете:

1. **Изменить статус доступности** - нажмите на иконку редактирования
2. **Добавить комментарий** - нажмите на иконку сообщения
3. **Добавить нового водителя вручную** - используйте кнопку "Добавить водителя"
4. **Создать связь** - назначьте водителя на тягач и прицеп во вкладке "Связи"

```

      └─ Вкладка "Водители"
```

## Технические детали

- **API URL**: `https://68fa3ce0ef8b2e621e7f53cf.mockapi.io/api/v1/drivers/name`
- **Метод**: GET
- **Формат ответа**: JSON Array
- **Защита от дубликатов**: По полю `licenseNumber`
- **Статус по умолчанию**: "Не работает"

---

**Совет**: Водители автоматически загружаются каждый раз при нажатии "Добавить заказ", но дубликаты не создаются благодаря проверке по номеру ВУ.
